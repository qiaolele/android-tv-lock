# 电视锁（TV Lock）—— 答题门禁 / 电视桌面

看电视、用手机前必须先做题的「门禁」。两种方式都能让“打开设备就先答题”：

- **电视（安卓 TV / 盒子）**：设为默认桌面，开机即进入答题锁屏，做对全部题目后进入「选择想看的电视」，选中即拉起对应 App。可看时长倒计时结束后自动弹回锁屏。
- **手机 / 平板**：开启「无障碍」后，**每次解锁屏幕都会自动弹出全屏锁屏**，必须做对全部题目才能进入系统主屏（或选中的 App）。验证通过后按「可看时长」放行，过期再锁——防沉迷闭环。

> 两条路线二选一即可，也可同时用（例如电视既设为桌面、又开着无障碍，双保险）。

## 功能
- 电视设为默认桌面；手机/电视解锁自动弹出门禁（无障碍服务，无需悬浮窗、不显示常驻通知）
- 随机算术题：运算类型（加/减/乘/除 多选）、数值上限（10/20/50/100/自定义）、题量、可看时长，均可在「设置」里改，本地记忆
- 答题成功 → 选择电视 App 或「系统主屏」→ 真拉起（APK 才有此能力；网页版只提示手动打开）
- 门禁守护（无障碍服务）：未通过验证时，关掉锁屏也会被重新弹回来（硬门禁）
- 倒计时结束 / 家长点「重新挑战」即重新锁定
- 界面流式自适应：占满视口、字号随屏幕缩放、避让刘海/状态栏/导航栏，竖屏横屏都不裁切

## 出包方式（二选一）

### A. GitHub Actions 云端出包（推荐，电脑零安装）
1. 把这个 `android-tv-lock` 文件夹作为仓库推到 GitHub。
2. 打开仓库的 **Actions** 标签页，点 **Run workflow**（推送 `main` 也会自动触发）。
3. 跑完后在本次运行的 **Artifacts** 里下载 `tv-lock-apk`（里面是 `app-debug.apk`）。
> 构建在云端完成，你电脑无需安装 Android Studio / JDK / Gradle。

### B. 本地 Android Studio
直接打开 `android-tv-lock` 文件夹 → 等待 Gradle 同步 → Run。

## 安装与授权

### 手机 / 平板（解锁自动弹门禁）
1. 把 `app-debug.apk` 装到手机（数据线 / 微信传文件 / U 盘）。
2. **首次打开会弹窗提示开启「无障碍」**——点「去设置」进入 **设置 → 无障碍 → 已安装的应用 / 电视锁**，开启它。
   - 这是“解锁后自动弹出锁屏”的可靠机制，**不需要悬浮窗、不会常驻通知**，比之前的方案干净且更稳定。
3. 想更狠（孩子按主页键也逃不掉）：到 **设置 → 应用 → 默认应用 → 桌面** 把「电视锁」设为默认桌面。不设也能用，只是主页键不再被接管。

### 电视 / 盒子（开机即锁屏）
- 装好 APK 后，到 **设置 → 应用 → 默认应用 → 桌面** 选择「电视锁」，重启即开机进入答题锁屏。
- 同时建议也开启「无障碍」（设置 → 无障碍 → 电视锁），保证解锁/息屏后再亮屏也能弹回锁屏。

## 家长退出 / 重置
- 手机：到 **设置 → 无障碍** 关闭「电视锁」（门禁不再自动弹）；或长按主页键切回原桌面；或 `adb uninstall com.example.tvlock`。
- 电视：改回原桌面后卸载；或在设置里关闭无障碍。

## 已知边界（诚实说明）
- **非 Root / 非设备所有者**的普通手机，门禁已接近“硬锁”，但极有心的孩子仍可能从通知/快捷设置等路径绕过（这是 Android 安全模型的限制，非本应用缺陷）。若需要**完全不可绕过**，需把设备设为「设备所有者 / Kiosk 模式」（企业级锁定），可另行探讨。
- 选择列表里的 App 包名（如 `com.tencent.qqlive`）为通用推测值，不同设备可能不同；装后用 `adb shell pm list packages | grep 腾讯` 查真实包名，改 `index.html` 的 `data-package` 重出包。

## 工程说明
- 纯原生 Android（Java），仅用系统自带 WebView，无第三方依赖。
- 网页 UI：`app/src/main/assets/index.html`（与上层 `../index.html` 同源，供电脑预览）。
- `MainActivity` 通过 `AndroidBridge` 暴露 `launchApp / launchHome / bringToFront / setUnlocked / clearUnlock` 给网页；并显式 `MATCH_PARENT` 保证 WebView 全屏（避免内容裁切）。
- `LockAccessibilityService`：无障碍服务，监听窗口切换/亮屏并在解锁后周期性兜底，未通过验证时把全屏锁屏拉到前台。
- `LockReceiver`：监听 `BOOT_COMPLETED`，开机拉起锁屏（作为默认桌面时由系统直接启动）。
