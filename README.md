# 电视锁（TV Lock）—— 答题门禁 / 电视桌面

看电视、用手机前必须先做题的「门禁」。两种方式生效：

- **电视（安卓 TV / 盒子）**：设为默认桌面，开机即进入答题锁屏，做对全部题目后进入「选择想看的电视」，选中即拉起对应 App。可看时长倒计时结束后自动弹回锁屏。
- **手机 / 平板**：安装并授予权限后，**每次解锁屏幕都会自动弹出锁屏**，必须做对全部题目才能进入系统主屏（或选中的 App）。验证通过后按「可看时长」放行，过期再锁——防沉迷闭环。

## 功能
- 两种形态共用一套界面：电视设为默认桌面；手机解锁自动弹出门禁
- 随机算术题：运算类型（加/减/乘/除 多选）、数值上限（10/20/50/100/自定义）、题量、可看时长，均可在「设置」里改，本地记忆
- 答题成功 → 选择电视 App 或「系统主屏」→ 真拉起（APK 才有此能力；网页版只提示手动打开）
- 后台守护服务：未通过验证时，关掉锁屏也会被重新弹回来（硬门禁）
- 倒计时结束 / 家长点「重新挑战」即重新锁定

## 出包方式（二选一）

### A. GitHub Actions 云端出包（推荐，电脑零安装）
1. 把这个 `android-tv-lock` 文件夹作为仓库推到 GitHub。
2. 打开仓库的 **Actions** 标签页，点 **Run workflow**。
3. 跑完后在本次运行的 **Artifacts** 里下载 `tv-lock-apk`（里面是 `app-debug.apk`）。
> 构建在云端完成，你电脑无需安装 Android Studio / JDK / Gradle。

### B. 本地 Android Studio
直接打开 `android-tv-lock` 文件夹 → 等待 Gradle 同步 → Run。

## 安装与授权（手机门禁必看）
1. 把 `app-debug.apk` 装到手机（数据线 / 微信传文件 / U 盘）。
2. **首次打开会弹窗要求「显示在其他应用上层 / 悬浮窗」权限**——必须授予！否则系统不允许应用在“解锁后”自动打开（Android 10+ 限制）。
3. （Android 13+）允许「通知」权限，守护服务需要常驻通知。
4. 想在手机上让“解锁即弹出”最稳：把本应用设为**默认桌面/主屏幕**（设置 → 应用 → 默认应用 → 桌面 → 电视锁）。不设也能用，但设为默认桌面后孩子按主页键也逃不掉。
5. 电视/盒子：设置 → 应用 → 默认应用 → 桌面，选择「电视锁」，重启验证。

## 家长退出 / 重置
- 手机：长按主页键切回原桌面；或到设置关闭「悬浮窗」权限（门禁不再自动弹）；或 `adb uninstall com.example.tvlock`。
- 电视：长按遥控器主页键切回原桌面；或改回原桌面后卸载。

## 已知边界（诚实说明）
- **非 Root / 非设备所有者**的普通手机，门禁已接近“硬锁”，但极有心的孩子仍可能从通知/快捷设置等路径绕过（这是 Android 安全模型的限制，非本应用缺陷）。若需要**完全不可绕过**，需把设备设为「设备所有者 / Kiosk 模式」（企业级锁定），可另行探讨。
- 选择列表里的 App 包名（如 `com.tencent.qqlive`）为通用推测值，不同设备可能不同；装后用 `adb shell pm list packages | grep 腾讯` 查真实包名，改 `index.html` 的 `data-package` 重出包。

## 工程说明
- 纯原生 Android（Java），仅用系统自带 WebView，无第三方依赖。
- 网页 UI：`app/src/main/assets/index.html`（与上层 `../index.html` 同源，供电脑预览）。
- `MainActivity` 通过 `AndroidBridge` 暴露 `launchApp / launchHome / bringToFront / setUnlocked / clearUnlock` 给网页。
- `LockReceiver`：监听 `BOOT_COMPLETED / SCREEN_ON / USER_PRESENT`，开机与解锁时拉起锁屏。
- `LockService`：前台守护服务，未通过验证时每 3 秒把锁屏重新拉到前台。
